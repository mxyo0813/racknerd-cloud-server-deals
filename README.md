**RackNerd 特价套餐续费会涨价吗？**

可以。控制面板里随时重装、切换发行版，主流 Linux 发行版都支持；Windows VPS 可在 Windows Server 2012 和 2016 之间切换。

72 小时内在控制面板自助免费更换，之后 $3 一次。买之前先 ping 测试 IP 能提前避开大概率被墙的网段。
